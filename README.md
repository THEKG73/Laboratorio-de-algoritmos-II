# Laboratorio de Algoritmos y Estructuras de Datos II

Este repositorio fue creado por **Kevin Gomes** y **David Garrido** con el objetivo de trabajar en conjunto para cumplir con las exigencias, prácticas y proyectos de la asignatura **Laboratorio de Algoritmos y Estructuras II**.

---

## 📋 Descripción del Proyecto

En este espacio se recopilan las implementaciones, pruebas y soluciones desarrolladas a lo largo del curso. Los objetivos clave del proyecto incluyen:

- Implementación de estructuras de datos lineales.
- Diseño y optimización de algoritmos de ordenamiento y búsqueda.
- Análisis de complejidad temporal y espacial en notación Big-O.
- Aplicación de buenas prácticas de programación, modularidad y control de versiones con Git.

---

## 🛠️ Tecnologías y Herramientas

- **Lenguaje principal:** Kotlin
- **Entorno de ejecución:** Linux / Bash
- **Control de versiones:** Git & GitHub
